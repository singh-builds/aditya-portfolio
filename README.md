## ⚡ JavaScript Features

The website uses JavaScript for several interactive features.

### Dark Mode

Users can switch between light and dark themes.

The selected theme is stored using:

```javascript
localStorage
```

This allows the selected theme to remain saved when the website is reopened.

### Mobile Menu

A responsive navigation menu is provided for smaller screens.

### Scroll Reveal

Website elements smoothly appear as the user scrolls through the page.

### Counter Animation

Project and technology statistics use animated counters when the statistics section becomes visible.

## 🚀 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/singh-builds/aditya-portfolio.git
```

### 2. Open the project

```bash
cd aditya-portfolio
```

### 3. Open in VS Code

```bash
code .
```

### 4. Run the website

Open `index.html` in your browser.

You can also use the **Live Server** extension in VS Code for easier development.
